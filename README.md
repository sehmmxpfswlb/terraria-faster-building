## Overview

Faster Building increases the tile placement and block breaking speed in Terraria, dramatically reducing the time spent on large construction projects and world preparation. The speed multiplier is configurable from a mild improvement through to near-instant for creative building sessions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Faster Building** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Fast Tile Placement** | Configurable tile placement speed multiplier for building sessions |
| **Fast Block Breaking** | Increased mining/breaking speed for excavation and clearing |
| **Configurable Speed** | Adjust placement and breaking speeds independently in mod config |
| **Creative Friendly** | Near-instant speeds available for creative or map-making sessions |
